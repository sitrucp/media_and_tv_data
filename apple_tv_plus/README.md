# Apple TV+ - Media Platform Event Creation

This is the **Apple TV+** module of the [Media TV and Movies - Calendar Event Creation System](../README.md). This module processes Apple TV+ viewing history data and creates Outlook calendar events.

## 📋 Overview

This module is part of a comprehensive, harmonized system for creating calendar events from media platform viewing data. For general information about the project architecture, features, and setup, see the [main project README](../README.md).

## 🎯 Apple TV+-Specific Features

- **Atlantic Timezone Handling**: Converts Apple TV+ Atlantic timestamps to UTC
- **Episode Formatting**: Formats episode information for calendar events
- **JSON Data Processing**: Processes Apple TV+ JSON export data

## 📊 Data Source

### **Input File**: `TV App Favorites and Activity.csv`
- **Source**: Apple TV+ viewing history export
- **Processing**: Converted from JSON and cleaned by `process_raw_data.py`
- **Format**: CSV with columns for title, start datetime, duration, etc.

## 🚀 Quick Start

### **Prerequisites**
- **Microsoft Graph API Credentials**: See [main project README](../README.md) for setup
- **Required Libraries**: `pandas`, `numpy`, `requests`, `pytz`, `ftfy`

### **Step 1: Obtain Apple TV+ Viewing History**
1. Go to [Apple Data and Privacy](https://privacy.apple.com)
2. Log in with your Apple ID
3. Request your data by selecting **"Request your data"** (may take a few days)
4. Once notified via email, download the data
5. Extract the file `TV App Favorites and Activity.json` from the path:
   ```
   Apple_Media_Services\Stores Activity\Apple TV and Podcast Information\TV App Favorites and Activity.json
   ```
6. **Replace the example file**: Copy your `TV App Favorites and Activity.json` to replace `TV App Favorites and Activity_example.json`

### **Step 2: Clean the Data**
```bash
python process_raw_data.py
```
- **Input**: `TV App Favorites and Activity.json` (raw Apple data)
- **Output**: `TV App Favorites and Activity.csv` (cleaned and preprocessed)

### **Step 3: Create Calendar Events**
```bash
python create_events.py
```
- **Input**: `TV App Favorites and Activity.csv` (processed data)
- **Output**: Outlook calendar events + logs

## ⚙️ Configuration Options

### **Testing & Validation**
```python
# In create_events.py
TEST_MODE = False      # Set to True for limited testing
TEST_LIMIT = 10        # Number of records to process in test mode
DRY_RUN = True         # Set to True to see what would happen without creating events
```

### **Date Filtering**
```python
# In create_events.py
LAST_EVENT_DATE = "2025-01-01"  # Only process events after this date
```

### **Usage Examples**

#### **Safe Validation (Recommended First Run)**
```python
TEST_MODE = False  # Process all records
DRY_RUN = True     # Don't create events, just show what would happen
```

#### **Limited Testing**
```python
TEST_MODE = True   # Process only limited records
DRY_RUN = False    # Actually create events
TEST_LIMIT = 5     # Process only 5 records
```

#### **Production Run**
```python
TEST_MODE = False  # Process all records
DRY_RUN = False    # Actually create all events
```
