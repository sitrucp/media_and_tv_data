# Google TV - Media Platform Event Creation

This is the **Google TV** module of the [Media TV and Movies - Calendar Event Creation System](../README.md). This module processes Google Play Store data and creates Outlook calendar events.

## 📋 Overview

This module is part of a comprehensive, harmonized system for creating calendar events from media platform viewing data. For general information about the project architecture, features, and setup, see the [main project README](../README.md).

## 🎯 Google TV-Specific Features

- **Data Conversion**: Converts Google Play Store JSON files to CSV
- **Data Merging**: Combines multiple CSV files into a unified dataset
- **Duration Estimation**: Estimates viewing duration for calendar events
- **EST Timezone Handling**: Converts Google TV EST timestamps to UTC

## 📊 Data Source

### **Input File**: `combine_library_purch_hist.csv`
- **Source**: Google Play Store data from Google Takeout
- **Processing**: Converted from JSON and merged by multiple processing scripts
- **Format**: CSV with columns for title, start time, duration, etc.

## 🚀 Quick Start

### **Prerequisites**
- **Microsoft Graph API Credentials**: See [main project README](../README.md) for setup
- **Required Libraries**: `pandas`, `numpy`, `requests`, `pytz`, `ftfy`

### **Step 1: Obtain Google Play Store Data**
1. Go to [Google Takeout](https://takeout.google.com/)
2. Select **Google Play Store** as the data source
3. Download the data as a ZIP file
4. Extract the following files from the path:
   ```
   takeout-<timestamp>.zip\Takeout\Google Play Store\
   ```
   - `Library.json`
   - `Purchase History.json`
5. **Replace the example files**: Copy your JSON files to replace `Library_example.json` and `Purchase History_example.json`

### **Step 2: Convert JSON Files to CSV**
```bash
python create_1_library_csv.py
python create_2_purchase_history_csv.py
```
- **Input**: `Library.json` and `Purchase History.json` (raw Google data)
- **Output**: `Library.csv` and `Purchase History.csv` (converted data)

### **Step 3: Merge Data**
```bash
python create_3_combine_library_purch_hist.py
```
- **Input**: `Library.csv` and `Purchase History.csv` (converted data)
- **Output**: `combine_library_purch_hist.csv` (merged dataset)

### **Step 4: Create Calendar Events**
```bash
python create_events.py
```
- **Input**: `combine_library_purch_hist.csv` (merged data)
- **Output**: Outlook calendar events + logs

## ⚙️ Configuration Options

### **Testing & Validation**
```python
# In create_events.py
TEST_MODE = False      # Set to True for limited testing
TEST_LIMIT = 10        # Number of records to process in test mode
DRY_RUN = True         # Set to True to see what would happen without creating events
```

### **Date Filtering**
```python
# In create_events.py
LAST_EVENT_DATE = "2025-01-01"  # Only process events after this date
```

### **Usage Examples**

#### **Safe Validation (Recommended First Run)**
```python
TEST_MODE = False  # Process all records
DRY_RUN = True     # Don't create events, just show what would happen
```

#### **Limited Testing**
```python
TEST_MODE = True   # Process only limited records
DRY_RUN = False    # Actually create events
TEST_LIMIT = 5     # Process only 5 records
```

#### **Production Run**
```python
TEST_MODE = False  # Process all records
DRY_RUN = False    # Actually create all events
```
