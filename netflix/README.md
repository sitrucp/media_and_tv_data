# Netflix - Media Platform Event Creation

This is the **Netflix** module of the [Media TV and Movies - Calendar Event Creation System](../README.md). This module processes Netflix viewing activity data and creates Outlook calendar events.

## 📋 Overview

This module is part of a comprehensive, harmonized system for creating calendar events from media platform viewing data. For general information about the project architecture, features, and setup, see the [main project README](../README.md).

## 🎯 Netflix-Specific Features

- **Timezone Conversion**: Converts Netflix local time to UTC for calendar events
- **Duration Calculation**: Calculates viewing duration from start/end times
- **Data Processing**: Cleans and filters Netflix viewing activity data

## 📊 Data Source

### **Input File**: `FilteredViewingActivity.csv`
- **Source**: Netflix viewing activity export
- **Processing**: Cleaned and filtered by `process_raw_data.py`
- **Format**: CSV with columns for title, start time, duration, etc.

## 🚀 Quick Start

### **Prerequisites**
- **Microsoft Graph API Credentials**: See [main project README](../README.md) for setup
- **Required Libraries**: `pandas`, `numpy`, `requests`, `pytz`, `ftfy`

### **Step 1: Obtain Netflix Viewing Activity Data**
1. Go to [Netflix Account Settings](https://www.netflix.com/account/getmyinfo)
2. Click **"Download your personal information"**
3. Wait for email confirmation from Netflix
4. Download the ZIP file from the provided link
5. Extract and locate: `netflix-report\CONTENT_INTERACTION\ViewingActivity.csv`
6. **Replace the example file**: Copy your `ViewingActivity.csv` to replace `ViewingActivity_example.csv`

### **Step 2: Process Netflix Data**
```bash
python process_raw_data.py
```
- **Input**: `ViewingActivity.csv` (raw Netflix data)
- **Output**: `FilteredViewingActivity.csv` (cleaned and filtered)

### **Step 3: Create Calendar Events**
```bash
python create_events.py
```
- **Input**: `FilteredViewingActivity.csv` (processed data)
- **Output**: Outlook calendar events + logs

## ⚙️ Configuration Options

### **Testing & Validation**
```python
# In create_events.py
TEST_MODE = False      # Set to True for limited testing
TEST_LIMIT = 10        # Number of records to process in test mode
DRY_RUN = True         # Set to True to see what would happen without creating events
```

### **Date Filtering**
```python
# In create_events.py
LAST_EVENT_DATE = "2025-01-01"  # Only process events after this date
```

### **Usage Examples**

#### **Safe Validation (Recommended First Run)**
```python
TEST_MODE = False  # Process all records
DRY_RUN = True     # Don't create events, just show what would happen
```

#### **Limited Testing**
```python
TEST_MODE = True   # Process only limited records
DRY_RUN = False    # Actually create events
TEST_LIMIT = 5     # Process only 5 records
```

#### **Production Run**
```python
TEST_MODE = False  # Process all records
DRY_RUN = False    # Actually create all events
```
