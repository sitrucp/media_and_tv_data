# Disney+ - Media Platform Event Creation

This is the **Disney+** module of the [Media TV and Movies - Calendar Event Creation System](../README.md). This module processes Disney+ viewing history data and creates Outlook calendar events.

## 📋 Overview

This module is part of a comprehensive, harmonized system for creating calendar events from media platform viewing data. For general information about the project architecture, features, and setup, see the [main project README](../README.md).

## 🎯 Disney+-Specific Features

- **Manual Date Management**: Manual datetime creation and calendar rearrangement support
- **Watch Time Calculation**: Calculates viewing duration from start/end times
- **Manual Date Filtering**: User-defined `LAST_EVENT_DATE` for precise control
- **EST Timezone Handling**: Converts Disney+ EST timestamps to UTC

## 📊 Data Source

### **Input File**: `watchlist_progress_raw_manual_dates.csv`
- **Source**: Disney+ watchlist progress data with manual datetime entries
- **Processing**: Manual datetime creation and data refinement
- **Format**: CSV with columns for title, start datetime, duration, etc.

## 🚀 Quick Start

### **Prerequisites**
- **Microsoft Graph API Credentials**: See [main project README](../README.md) for setup
- **Required Libraries**: `pandas`, `numpy`, `requests`, `pytz`, `ftfy`

### **Step 1: Obtain Disney+ Data**
**Note**: Disney+ doesn't provide a direct viewing history export. This module gets your Disney watchlist progress data from the Disney website when you are logged into the site. This watchlist progress does not include the datetime you watched the show. It only includes the percent progress of the show watch. Therefore you must manually enter a start datetime in the data retrieved from the watchlist file. Note to Disney Plus devs and product managers you should create and provide a download your data feature like the rest of the streaming services so people can get this data without scraping your site.

1. Use the Disney+ API wrapper to get watchlist data
2. Run `get_watchlist.py` to retrieve watchlist information
3. Use `update_manual_watchlist.py` to add manual datetime entries
4. The final processed file should be `watchlist_progress_raw_manual_dates.csv`
5. **Replace the example file**: Copy your `watchlist_progress_raw_manual_dates.csv` to replace `watchlist_progress_raw_manual_dates_example.csv`

### **Step 2: Create Calendar Events**
```bash
python create_events.py
```
- **Input**: `watchlist_progress_raw_manual_dates.csv` (processed data with manual dates)
- **Output**: Outlook calendar events + logs

## ⚙️ Configuration Options

### **Testing & Validation**
```python
# In create_events.py
TEST_MODE = False      # Set to True for limited testing
TEST_LIMIT = 10        # Number of records to process in test mode
DRY_RUN = True         # Set to True to see what would happen without creating events
```

### **Date Filtering**
```python
# In create_events.py
LAST_EVENT_DATE = "2025-09-24"  # Only process events after this date (user-defined)
```

### **Usage Examples**

#### **Safe Validation (Recommended First Run)**
```python
TEST_MODE = False  # Process all records
DRY_RUN = True     # Don't create events, just show what would happen
```

#### **Limited Testing**
```python
TEST_MODE = True   # Process only limited records
DRY_RUN = False    # Actually create events
TEST_LIMIT = 5     # Process only 5 records
```

#### **Production Run**
```python
TEST_MODE = False  # Process all records
DRY_RUN = False    # Actually create all events
```
