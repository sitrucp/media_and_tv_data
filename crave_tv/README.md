# Crave TV - Media Platform Event Creation

This is the **Crave TV** module of the [Media TV and Movies - Calendar Event Creation System](../README.md). This module processes Crave TV viewing history data and creates Outlook calendar events.

## 📋 Overview

This module is part of a comprehensive, harmonized system for creating calendar events from media platform viewing data. For general information about the project architecture, features, and setup, see the [main project README](../README.md).

## 🎯 Crave TV-Specific Features

- **Web Scraping Data**: Processes JSON data from Crave TV web interface
- **Series/Movie Distinction**: Handles different content types appropriately
- **Rate Limiting**: Built-in support for API rate limits
- **EST Timezone Handling**: Converts Crave TV EST timestamps to UTC

## 📊 Data Source

### **Input File**: `raw_data_clean.csv`
- **Source**: Crave TV web interface (Dev Tools network data)
- **Processing**: Merged and refined from multiple JSON files by `process_raw_data.py`
- **Format**: CSV with columns for title, start datetime, content type, etc.

## 🚀 Quick Start

### **Prerequisites**
- **Microsoft Graph API Credentials**: See [main project README](../README.md) for setup
- **Required Libraries**: `pandas`, `numpy`, `requests`, `pytz`, `ftfy`

### **Step 1: Obtain Crave TV Viewing History**
**Note**: Crave TV doesn't provide a data export feature. Data must be obtained from their web interface.

1. Go to [Crave TV Watch History](https://www.crave.ca/en/cravings?tab=watch-history)
2. Open Dev Tools (F12) and go to the **Network** tab
3. Look for the following JSON objects:
   - `watchHistory?pageNumber=0&pageSize=500` (may have multiple pages)
   - `graphql_0.json` (may have multiple instances)
4. Copy the JSON from both objects and save files with their original names:
   - `watchHistory_pageNumber_0.json`
   - `graphql_0.json`
5. **Replace the example files**: Copy your JSON files to replace `watchHistory_pageNumber_0_example.json` and `graphql_0_example.json`

### **Step 2: Clean the Data**
```bash
python process_raw_data.py
```
- **Input**: Multiple JSON files from Crave TV web interface
- **Output**: `raw_data_clean.csv` (merged and refined data)

### **Step 3: Create Calendar Events**
```bash
python create_events.py
```
- **Input**: `raw_data_clean.csv` (processed data)
- **Output**: Outlook calendar events + logs

## ⚙️ Configuration Options

### **Testing & Validation**
```python
# In create_events.py
TEST_MODE = False      # Set to True for limited testing
TEST_LIMIT = 10        # Number of records to process in test mode
DRY_RUN = True         # Set to True to see what would happen without creating events
```

### **Date Filtering**
```python
# In create_events.py
LAST_EVENT_DATE = "2025-01-01"  # Only process events after this date
```

### **Usage Examples**

#### **Safe Validation (Recommended First Run)**
```python
TEST_MODE = False  # Process all records
DRY_RUN = True     # Don't create events, just show what would happen
```

#### **Limited Testing**
```python
TEST_MODE = True   # Process only limited records
DRY_RUN = False    # Actually create events
TEST_LIMIT = 5     # Process only 5 records
```

#### **Production Run**
```python
TEST_MODE = False  # Process all records
DRY_RUN = False    # Actually create all events
```
